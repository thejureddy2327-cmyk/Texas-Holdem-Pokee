# Texas Hold’em Friends V2

A polished private-room, virtual-chip Texas Hold’em web app.

Features: 2–9 players, shareable room codes, custom blinds, mobile poker table, player seats, fold/check/call/raise/all-in, showdown, chat, and next-hand flow.

## Run
Install Node.js 18+, then:

    npm install
    npm start

Open http://localhost:3000. Deploy the folder to a Node.js host supporting WebSockets for online play.

This version is for virtual chips only; it does not support real-money wagering.
